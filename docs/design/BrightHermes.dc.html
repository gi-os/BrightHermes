What separates them
1A Ledger. Sender labels on every message, tiles labeled left-aligned, one row per fact. Reads like a log — right if the user's mental model is "June keeps a record for me." Costs 12 dp of label above each message, so fewer messages fit.
1B Transcript. No labels; June is left and full-width, you are right and set in medium. Ruled timestamp dividers, chips as full-width rows with a return glyph, PTT inverts the panel to white so the held state is unmistakable at arm's length. Denser, quieter, more Light-native — but alignment alone has to carry authorship.
Open in both: the deck grid in 1B gives the agent digest a full-width row (it's the moat tile), 1A treats all six tiles as equals. Tell me which chassis to keep and I'll draw pairing, edit mode, digest detail and the lockscreen render on it.
